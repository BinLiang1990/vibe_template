# vibe_template

Starter template with a set of shared Claude Code skills baked in
(`afk`, `spec-planner`, `implementation-pilot`, `cto-pr-review`,
`codex-review`, `kimi-review`, `ui-ux-pro-max`, ...). Skill source lives in
[`skill/`](skill/) and is version-controlled; `.claude/skills/` is a
generated, gitignored set of links into it.

## Using this template

**Option A — GitHub "Use this template" button** (recommended for a new
project): click *Use this template* on the repo page, then clone your new
repo and run the setup step below.

**Option B — clone directly**:

```bash
git clone https://github.com/BinLiang1990/vibe_template.git
```

## One-time setup after cloning

Claude Code loads skills from `.claude/skills/`, but that folder isn't
committed — junctions/symlinks don't survive a git clone as links (git would
either drop them or duplicate the target's files), so every clone or
worktree needs to materialize them once from `skill/`:

- **macOS / Linux**: `bash scripts/link-skills.sh`
- **Windows**: `powershell -File scripts/link-skills.ps1`

This creates a symlink (Unix) or NTFS junction (Windows) per skill under
`.claude/skills/<name>` pointing at `skill/<name>`. Re-run it any time a new
skill is added to `skill/` — it skips any link that already exists.

After that, open the project in Claude Code and the skills listed above are
available as slash commands (e.g. `/afk`, `/spec-planner`).

## Adding or updating a skill

Edit files under `skill/<name>/`, commit them — that's the single source of
truth. Don't edit anything under `.claude/skills/` directly, it's
regenerated by the link script and gitignored.
